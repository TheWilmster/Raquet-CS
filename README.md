"Lightweight free (as in free speech AND free beer) SDL2 based Game Engine/Framework to providing tools to make games resembling the computers of yesteryear." -Jessie J. T. <br>

# Features
- 2D 4 Color Tile-Based Rendering
- Audio Playback using SDL Mixer
- Keyboard and Mouse Input Handling
- Collision Detection
- Video-Game-Specific Math Functions
- Palette Swapping
- Basic Game Object Management (Actors)
